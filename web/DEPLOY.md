# Развёртывание дашборда для сторонних пользователей

Дашборд — **полностью статический** сайт: HTML + JS + CSS + JSON-данные.
Никакого сервера/бэкенда не нужно. Папку `dist/` можно выложить на любой
статический хостинг.

## Как обновить данные и пересобрать

1. Заменить Excel-файлы в корне проекта (`Общая.xlsx`, `Спр.xlsx`, `Короткие названия.xlsx`).
2. Пересчитать JSON:
   ```bash
   python export_data.py
   ```
3. Собрать статику:
   ```bash
   cd web
   npm run build
   ```
   Готовый сайт окажется в `web/dist/` (внутри уже лежат `data/*.json`).

## Быстро показать локально / в сети

```bash
cd web
npm run preview
```
Vite поднимет сайт и подскажет адрес (`Local` и `Network`). Адрес из строки
`Network` (вида `http://192.168.x.x:4173`) можно открыть с телефона или другого
компьютера в той же сети.

## Выложить в интернет (бесплатные варианты)

Любой из вариантов — просто отдать содержимое папки `web/dist/`:

- **Netlify Drop** — https://app.netlify.com/drop — перетащить папку `dist/` в окно браузера, получить ссылку.
- **Vercel** — `npx vercel deploy web/dist --prod` (нужен аккаунт).
- **GitHub Pages** — закоммитить содержимое `dist/` в ветку `gh-pages`.
- **Cloudflare Pages / любой S3-бакет / хостинг** — залить `dist/` как статику.

> Если сайт будет жить не в корне домена, а в подпапке (например
> `example.com/dashboard/`), собери с базовым путём:
> ```bash
> npm run build -- --base=/dashboard/
> ```
> Загрузка данных уже учитывает `BASE_URL`, так что пути не сломаются.
