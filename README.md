# 🎙️ Подкаст · Аналитика

Интерактивный дашборд аналитики подкаста в стиле глассморфизм.
Данные считаются на Python из Excel и экспортируются в JSON, фронтенд — React
(Vite + TypeScript + Recharts). Сайт полностью статический.

## Структура

```
podcast_analytics/     # Python: загрузка Excel + расчёты (RSI, воронки, кривые жизни)
export_data.py         # генерирует web/public/data/*.json из Excel
web/                   # React-фронтенд (Vite + TS + Recharts)
  public/data/*.json   # данные для сайта (коммитятся; собираются из Excel)
  src/                 # компоненты, страницы, дизайн-система
dashboard.py           # прежний Streamlit-дашборд (для сверки чисел)
```

Сырые Excel-файлы (`*.xlsx`) в репозиторий **не** коммитятся — публикуется только
сгенерированный JSON.

## Локальная разработка

```bash
# 1. Пересчитать данные из Excel (после изменения .xlsx)
python export_data.py

# 2. Запустить фронтенд
cd web
npm install
npm run dev
```

## Обновление данных

1. Заменить Excel-файлы в корне проекта.
2. `python export_data.py` — обновит `web/public/data/*.json`.
3. Закоммитить изменённый JSON и запушить — сайт пересоберётся автоматически.

### Источники данных

- `Общая.xlsx`, `Спр.xlsx`, `Короткие названия.xlsx` — базовые метрики
  (старты, стримы, слушатели, часы, %) → `records.json` + `meta.json`.
- `Старты.xlsx`, `Стримы.xlsx` — демография (пол / возраст / город) →
  `demographics.json`. Если этих файлов нет, экспорт не падает — просто
  демографические блоки на сайте не отображаются.

Демографические визуализации: **пол** — кольцевая диаграмма, **возраст** —
горизонтальная линейчатая, **город** — баблы на карте (размер ∝ метрике).
Есть переключатель Старты/Стримы. Показываются на всех трёх страницах
(общая — по всему подкасту, анализ/сравнение — по выбранным выпускам).
Координаты городов и нормализация — в [podcast_analytics/geo.py](podcast_analytics/geo.py).

## Доступ по паролю

Дашборд закрыт экраном ввода пароля (по умолчанию `skufim2026`).

> ⚠️ Это **лёгкая** защита «от случайных глаз», а не настоящая безопасность:
> сайт статический и публичный, поэтому JSON-данные в `web/public/data`
> технически доступны напрямую по ссылке. Для настоящей защиты нужен приватный
> хостинг или прокси с авторизацией (например, Cloudflare Access).

Сменить пароль — в [web/src/config/access.ts](web/src/config/access.ts):
получите SHA-256 нового пароля и вставьте вместо текущего хэша:

```bash
node -e "console.log(require('crypto').createHash('sha256').update('НОВЫЙ_ПАРОЛЬ','utf8').digest('hex'))"
```

## Мобильные устройства

Вёрстка адаптивная: на телефоне навигация превращается в закреплённую нижнюю
панель, KPI — по два в ряд, карта и графики подстраиваются под ширину экрана.

## Деплой (GitHub Pages)

Настроен автоматический деплой через GitHub Actions
([.github/workflows/deploy.yml](.github/workflows/deploy.yml)):
при каждом `push` в ветку `main` сайт собирается и публикуется на GitHub Pages.

Разовая настройка после первого пуша: **Settings → Pages → Build and deployment →
Source: GitHub Actions**.

Адрес сайта: `https://<ваш-логин>.github.io/<имя-репозитория>/`
(базовый путь подставляется в сборку автоматически из имени репозитория).
